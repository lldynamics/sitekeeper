# 第二轮改进实施记录（2026-09-09）

本轮基于本地提交 `87c8f90`，由 GPT-6 Astra 负责备份可靠性及集成复核，GPT-5.6 Sol 并行处理业务规则、界面和图片加载。提交范围为本地代码与验证记录，不包含远端推送或 App Store 发布。

| 方向 | 实施结果 |
| --- | --- |
| 恢复事务 | 在替换附件之前持久化恢复日志、旧元数据及附件副本；启动先恢复未结束事务，再加载业务数据。已写入新数据但事务终态写入失败时暂停保存，保留恢复包供重试。 |
| 维护互斥 | 加载失败、恢复期间禁止清空、清理和回收站恢复；本机/云端备份导出持有读取租约，归档期间阻止清理和恢复。失败与取消释放租约。 |
| iCloud 成功状态 | 区分本地写入、待上传、已上传和错误。ZIP 与 SHA 文件均报告上传完成才更新成功时间；未知 pending 状态暂停重复自动备份。只淘汰已上传的历史备份。 |
| 财务口径 | 正式收入、支出、未结算、缺票以及往来明细使用一致状态规则；草稿和归档不计入正式指标。存在零成本明细时保留零值，不回退旧手工金额；首页、详情与 PDF 使用同一规则。 |
| 材料报价 | 批量生成时明确选择沿用材料单价、统一设置对外报价或留空待补；不预选。单项快捷导入保留待补价格。 |
| 报价转合同 | 明确工程、已确认版本、条目名称、范围及原/新金额；确认前重新核验快照。缺失或非法计价输入阻止写入；有效显式合同金额可独立使用。 |
| 库存一致性 | 名称按空白和大小写归一，规格及单位保持隔离，沿用 Decimal 数量累计。 |
| 历史人工单位 | 可筛选和定位待确认记录，显式批量确认工时/工天。确认弹窗冻结记录范围，不换算历史数值或金额。 |
| 大字号与保存反馈 | 我的页面在辅助字号下纵向布局；项目状态使用菜单；用户名可编辑保存。手动保存依据实际异步结果报告成功或失败。 |
| 图片与搜索 | 文件 URL 经 ImageIO 按显示尺寸降采样，保留方向与透明通道；随手记项目名索引只构造一次，先筛选后排序。搜索移至后台，输入防抖，取消及过期结果不回写。 |
| 持续验证 | 固定并校验 XcodeGen 2.46.0、SwiftFormat 0.61.1、SwiftLint 0.63.2 的发布包 SHA-256；新增恢复日志故障、业务规则、图片和搜索测试，并把真实 ZIP 导出/清空/恢复/重启流程加入 UI 门禁。 |

## 性能基线

Xcode 26.6、iOS 26.5、专用 iPhone 17 Pro Max 模拟器，Debug 构建。搜索与编码各测量 5 次；图片测试测量一组 200 次连续加载。以下是当前算法基线，不是旧版本对比，也不代表真机滚动帧率：

- 10,000 条随手记、1,000 个工程，三种查询合计平均 **0.237 秒**。
- 10,000 条记录的按键排序的 JSON 编码平均 **0.035 秒**。
- 一张 4,000 × 3,000 JPEG 连续执行 200 次、最大边 360 px 的降采样，约 **1.037 秒**；测试进程物理内存峰值约 **96 MB**，驻留内存增长低于 128 MiB 的断言通过。
