## 验收

验证环境：Xcode 26.6、iOS 26.5 模拟器、专用 iPhone 17 Pro；不使用现有用户模拟器的数据。

- 干净构建完成 Swift 编译；首次链接因临时磁盘空间不足失败，清理本次任务产物后重新构建通过。最终 Swift 源码编译无警告；工具另有无 AppIntents 依赖时跳过元数据提取的提示。
- 完整单元测试：353 项、59 组通过。
- 512 MiB 真实备份导出、删除源附件、恢复并校验通过，测试耗时约 7.4 秒。旧逐位 CRC 压力运行已中断，不作为通过证据；新实现使用系统 zlib，标准向量、分块增量和旧 ZIP 兼容测试均通过。
- 9 项发布边界检查、8 个构建守卫失败传播、严格本地化、隐私文档生成一致性通过。
- 中英文各补齐 714 条资源；源码覆盖 0 缺失、占位符 0 不一致，检查器自身 6 项测试通过。
- SwiftFormat：575 份 Swift 文件无需调整。SwiftLint：50 个长度/复杂度提示、0 个严重问题，baseline 未修改；暂存范围 22 个提示、0 个严重问题。
- 完整 UI 回归：19 项通过、0 失败、0 跳过，包含此前默认关闭的样例数据扩展场景；排除的 2 项仅用于生成 App Store 截图。英文录入页和最大动态字号截图已目视复核。
